# Homework Assignment 1

In this assignment, we explored various types of environmental injustices by using the EJScreen tool and importing the dataset into our folder. We specifically looked at the relationship between the proportion of low income residents and hazard waste proximity in San Bernardino county. In order to determine if there is a correlation, we graphed the two factors to analysis the environmental injustice associated with people with low income and their susceptibility to a greater extent of toxic waste exposure. 

## Inside the Repo:

This repository contains a data folder that holds environmental and demographic information for the U.S. at the census tract and block group levels by EJScreen. It also has a PDF of the metadata for this dataset and explains how the data was collected and in what ways were they expressed. However we have  a gitignore file to prevent the large dataset from bloating the repository. The main code and graphs are within the quarto document hw1.qmd. Finally the README.md file is a summary of what is contained inside the repository and what it accomplishes.
